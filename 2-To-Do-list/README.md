# ✅ To-Do List App

A modern and responsive **To-Do List Application** built with **HTML5, CSS3, and JavaScript**. It helps users organize daily tasks with a clean interface and stores data using **LocalStorage**, so tasks remain even after refreshing the page.

(https://uiforge-dev.github.io/to-do-list)

## ✨ Features

- ➕ Add New Tasks
- ✏️ Edit Existing Tasks
- 🗑️ Delete Individual Tasks
- ✅ Mark Tasks as Completed
- 🔍 Search Tasks
- 🎯 Filter Tasks (All, Active, Completed)
- 📊 Task Statistics
- 💾 LocalStorage Support
- 🧹 Clear Completed Tasks
- ❌ Delete All Tasks
- ⌨️ Press Enter to Add Tasks
- 📱 Fully Responsive Design
- 🎨 Modern Glassmorphism UI
