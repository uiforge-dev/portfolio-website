# 🔐 Password Generator

A modern, secure, and responsive **Password Generator** built with **HTML, CSS, and JavaScript**.

Generate strong passwords instantly with customizable options, a password strength indicator, and one-click copy functionality.

---

## 🌐 Live Demo

(https://uiforge-dev.github.io/password-generator)

## ✨ Features

- 🔐 Generate secure random passwords
- 🔢 Adjustable password length (8–32 characters)
- 🔠 Include uppercase letters
- 🔡 Include lowercase letters
- 🔢 Include numbers
- 🔣 Include symbols
- 📊 Password strength indicator
- 📋 Copy password to clipboard
- 🔒 Secure password generation using `crypto.getRandomValues()`
- 🔀 Fisher–Yates shuffle algorithm
- 💎 Modern Glassmorphism UI
- 📱 Fully Responsive
- ⚡ Smooth animations

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/uiforge-dev/password-generator.git
```

Open the project folder.

Open **index.html** in your browser.

No installation is required.

---

## 💡 How to Use

1. Select the password length.
2. Choose the character types.
3. Click **Generate Password**.
4. Click the **Copy** button.
