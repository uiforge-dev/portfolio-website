# ⏱️ Stopwatch App

A modern and responsive **Stopwatch App** built using **HTML5, CSS3, and JavaScript**. This project allows users to accurately measure elapsed time with Start, Pause, Reset, and Lap functionalities. It is designed with a clean UI and works seamlessly across desktop, tablet, and mobile devices.

## ⚙️ Installation

1. Clone the repository

```bash
git clone https://github.com/uiforge-dev/stopwatch-app.git
```

2. Open the project folder.

3. Run `index.html` in your browser.

---

## 🎮 How to Use

1. Click **Start** to begin timing.
2. Click **Pause** to stop temporarily.
3. Click **Start** again to continue.
4. Click **Lap** to save the current time.
5. Click **Reset** to clear the timer and lap records.
